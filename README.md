# PART3-POE-P# Java Registration and Messaging System

A Java application developed to demonstrate object-oriented programming concepts, user registration, login functionality and message management.

## Project Overview

The Java Registration and Messaging System is a software development project created as part of my programming studies.

The project is organised into separate Java classes to manage registration, login, messages and message storage.

It demonstrates the use of Java programming concepts and structured application development.

## Technologies Used

- Java
- Apache NetBeans
- Object-Oriented Programming
- Git and GitHub

## Project Components

| Java Class | Description |
|---|---|
| `Registration.java` | Handles user registration functionality. |
| `Login.java` | Contains login-related functionality. |
| `Message.java` | Represents message-related information. |
| `MessageStorage.java` | Handles message storage functionality. |

## Running the Project

1. Install Java Development Kit (JDK).
2. Open Apache NetBeans.
3. Open the Registration project.
4. Allow NetBeans to load the project.
5. Run the application using the Run Project option.

The project may require additional configuration depending on its original setup.
